# 缝纫工作室 · 免登录版

六个模块：灵感收藏、纸样资料库、设计打版、面料衣柜、制作项目、成品展厅。

此版本为独立静态网页，不依赖 ChatGPT 登录或后端接口。每位访客的资料通过 IndexedDB 保存在自己的浏览器。图片和纸样作为数据文件保存，完整备份可导出和合并导入。清除网站数据会清除该浏览器中的资料；换设备请先导出备份。

## 开发

安装 package.json 中的依赖，执行 `npm run build`。输出为 dist/，可部署到任何静态托管服务。Vite 的相对路径配置支持 GitHub Pages 子目录。

这里的示例库存和作品均为示例。立领上衣 PDF/SVG 是混合天使中胸的首版试缝纸样，腰节、胸高等仍有暂估，需先试缝。三维模板用于轮廓和贴图预览，不是布料仿真；滑杆不会修改导出的原版纸样。参考图自动识别打版尚未接入。

项目不包含私密云端资料、密钥或账户凭据。
